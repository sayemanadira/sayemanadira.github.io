Kalman Filter for Acoustic Localization: Experimentation and Simulation

Spring 2026 State Estimation Partner(s): Emily Barr Python, Alphabot, C++
Raspberry Pi Alphabot Python C++ Time-Difference of Arrival (TDOA) Data Acquisition and Analysis Hardware Implementation

Overview

This project focuses on implementing a Kalman filter for acoustic localization, exploring both experimentation and simulation aspects to improve the accuracy and robustness of position estimation.

Technical Details

This project involves the implementation of a Kalman filter for acoustic localization. The filter is applied in post-processing to estimate the position of a sound source based on time-difference of arrival (TDOA) measurements from multiple microphones. The project includes both simulation and real-world experimentation using an Alphabot equipped with a microphone array. The Kalman filter is designed to handle noisy measurements and dynamic environments, providing accurate localization even in the presence of uncertainties. The implementation is done in Python for simulation and C++ for real-time processing on the Alphabot, demonstrating the practical application of state estimation techniques in acoustic localization scenarios.

Results

Although our implementation shows promising results in simulation, the real-world performance was limited by environmental factors and measurement noise. The AlphaBot was equipped with a four-microphone array, but the audio data was collected at a very low sampling rate. Because the timing differences between microphones are extremely small, the system could not reliably capture when each beacon signal arrived. As a result, the frequency-based processing method we originally wanted to use did not work well, and we instead used changes in signal volume to separate the beacon sounds. The real audio-based position estimates were very noisy. Many of the estimated positions were far from the robot’s actual path and even far from the beacon locations. Because the measurements were so unreliable, the Kalman filter learned to trust the robot’s motion model much more than the audio measurements. This caused the final filtered trajectory to look smooth, but it mostly reflected the predicted robot motion rather than corrections from the microphones. Overall, the project showed that the Kalman filter and TDOA localization pipeline is promising, but the hardware setup limited the success of the physical implementation. The biggest takeaway was that measurement quality matters a lot: with reliable audio timing, the filter can improve localization, but with noisy or low-resolution measurements, the filter will mostly ignore the sensor data and rely on the motion model instead
